# PythonBase

## description
This is a homework project for the basic course of python

## Installation
1. Clone the repository https://github.com/Petr1986/PythonBase
2. Go to the project directory cd PythonBase
3. Install dependencies pip install requirements.txt
4. The repository is divided by homework numbers (for example: homework1).
Each directory is divided into separate modules for each task.
There is also a separate directory with tests for each module.
